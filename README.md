# Grade Curricular e Repositório de Estudos

Este repositório centraliza os conteúdos pedagógicos, códigos-fonte e anotações teóricas divididos em quatro pilares fundamentais da tecnologia.

---

## Visão Geral dos Módulos

### 1. Arquitetura IoT & Sistemas Embarcados
Focado na integração entre hardware de baixo nível e software de alto nível.
* **Hardware & Prototipagem:** Microcontrolador ATmega328P, eletrônica básica, sensores e atuadores.
* **Firmware (C++):** Manipulação de GPIOs, temporização não-bloqueante (`millis()`) e comunicação serial.
* **Integração Python:** Captura de dados via `pySerial`, geração de logs CSV e dashboards (`matplotlib`/`Dash`).
* **Fluxo de Dados:** Leitura Física → Envio Serial → Tratamento Python → Armazenamento.

### 2. Levantamento de Requisitos
Aborda o mapeamento de necessidades e a documentação técnica de projetos.
* **Classificação:** Diferenciação entre Requisitos Funcionais (RF) e Não Funcionais (RNF).
* **Elicitação:** Técnicas de Brainstorm, Entrevistas estruturadas e Prototipagem de telas.
* **Modelagem:** Diagramas UML (Casos de Uso e Sequência) e mapeamento BPMN.
* **Artefatos:** Especificação de Requisitos (SRS), Matriz de Rastreabilidade e Atas.

### 3. Lógica de Programação & Controle de Versão
Base prática de desenvolvimento de software e boas práticas de código.
* **Git & GitHub:** Comandos essenciais (`init`, `status`, `add`, `commit`, `push`, `pull`, `clone`).
* **Sintaxe Python:** Tipos de dados, operadores lógicos e estruturas condicionais (`if/elif/else`).
* **Estruturas Avançadas:** Laços (`while`/`for`), coleções (Listas, Tuplas, Dicionários) e funções.
* **Robustez:** Tratamento de erros com blocos `try/except`.

### 4. Fundamentos de Sistemas Operacionais
Compreensão de como o software interage com a infraestrutura da máquina.
* **Arquitetura de SO:** Divisão entre Modo Kernel e Modo Usuário.
* **Virtualização:** Conceitos de Hipervisores Tipo 1 e Tipo 2 (Máquinas Virtuais).
* **Interface de Linha de Comando (CLI):** Operação de terminais Windows (CMD) e Linux/macOS.
* **Gerenciamento Interno:** Ciclo de vida de Processos/Threads, Escalonamento, Deadlocks e Paginamento de Memória.

---

## Tecnologias e Ferramentas Utilizadas

* **Linguagens:** C++ (Arduino) e Python 3.
* **Controle de Versão:** Git e GitHub.
* **Ambientes:** Terminais CLI (Bash/PowerShell) e Hipervisores de Máquinas Virtuais.
