📚 Sobre a disciplina

A disciplina de Linguagem de Marcação aborda a criação e estruturação de páginas web, utilizando elementos responsáveis pela organização e apresentação do conteúdo.

🚀 Projetos

Os projetos desenvolvidos nesta disciplina têm como objetivo aplicar na prática os conceitos de HTML e estruturação de páginas web, criando interfaces organizadas e funcionais.

🎯 Objetivo

Desenvolver conhecimentos em Linguagem de Marcação, aprendendo a estruturar páginas web utilizando boas práticas de HTML e os principais elementos utilizados no desenvolvimento para a Web.
